DreamLab Canvas portable mode

While this file sits next to dreamlab-canvas.exe, DreamLab Canvas keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the DreamLabCanvasData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move DreamLab Canvas with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\DreamLab Canvas) instead.
If DreamLabCanvasData can't be written (for example on a read-only drive), DreamLab Canvas says so and
uses %APPDATA%\DreamLab Canvas instead.
